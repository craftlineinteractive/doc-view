Client Engine Protocols & Runtime Specifications

key

1. Security Handshake

AES-256 local decryption via native C++ Pdfium engine. Passwords never touch the cloud, zero telemetry emitted during validation.

PDFium::FPDF_ClosePassword()
tag

2. Bounds Check

Clamped index parser with inline assertion: 1 ≤ N ≤ TotalPages. Prevents out-of-range render exceptions and negative buffer reads.

Renderer::SeekPageIndex(n)
share

3. Damaged Intent Handover

Invokes ACTION_VIEW on Android and UIDocumentInteractionController on iOS as external system salvage fallback.

OS::TriggerDocumentShare()
delete_sweep

4. Storage URI Eviction

On Scoped Storage FileNotFoundException, the cached thumbnail and recent list entries are immediately flagged for purge.

MediaStore::PruneDeadUri()
