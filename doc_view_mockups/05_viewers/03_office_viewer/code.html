Architectural Directives

Core rendering rules and engine parameters enforced across handheld devices.

offline_bolt Offline Rust Engine

POI/OpenXML decompressed in memory using zero-copy Rust streaming. Uncompressed packages are validated entirely inside the local device sandbox.

view_column 3,000-Row Clamping

XLSX grids mount a maximum window of 3,000 continuous rows into the DOM. Cell virtualization unmounts off-screen matrix items to restrict footprint under 65MB.

invert_colors_off Non-Inversion Fidelity

In Dark Navy mode, outer canvas transforms to #11131B, but the document sheets remain clean #FFFFFF. High-contrast diagrams and corporate typography are never inverted.

block Zero In-Reader Ads

Document viewports have a strict zero-ad and zero-bottom-navigation mandate. Screen real estate is entirely preserved for uninterrupted reading and matrix manipulation.
