# Google Play Content Rating (IARC Questionnaire Guide): Doc View

This document provides expected responses for the International Age Rating Coalition (IARC) questionnaire in Google Play Console for Doc View.

> [!NOTE]
> Verify all answers in Google Play Console upon submission.

---

## 1. Category Selection
- **App Category**: **Utility, Productivity, Communication, or Other** (Productivity / Document Management).

---

## 2. Questionnaire Answers

| Question | Answer | Rationale |
|---|---|---|
| **Violence**: Does the app contain any violent content? | **No** | Offline productivity tool. |
| **Sexuality**: Does the app contain any sexual content or nudity? | **No** | Offline productivity tool. |
| **Language**: Does the app contain potentially offensive language? | **No** | Professional document viewer. |
| **Controlled Substances**: Does the app contain references to drugs, alcohol, or tobacco? | **No** | N/A. |
| **Gambling**: Does the app simulate gambling or contain real gambling? | **No** | N/A. |
| **User Interaction**: Does the app natively allow users to interact or exchange messages with others? | **No** | Doc View has no chat, public forums, or social messaging. Sharing is initiated via the standard Android OS share sheet. |
| **Location Sharing**: Does the app share the user's current physical location with other users? | **No** | Zero location sharing. |
| **In-App Purchases**: Does the app allow users to purchase digital goods? | **Yes** | Offers optional Doc View Premium subscription via Google Play Billing. |
| **Web Browser**: Does the app contain an unrestricted open-web browser? | **No** | Contains specialized document rendering views (Office Viewer WebView for local documents only) and external link dispatch via standard device browser for privacy/terms URLs. |
